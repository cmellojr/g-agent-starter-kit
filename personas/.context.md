Defines the specialized AI roles (personas) used in the multi-agent framework
to handle distinct stages of software development tasks.

## Summary

- README.md — schema definition, available personas, and execution models
- architect.md — persona that designs implementations and before/after states
- coder.md — persona that writes software and applies coding styles
- contextualizer.md — persona that maintains directory contexts and feature maps
- maestro.md — conductor persona that boots, parses, and orchestrates tasks
- reviewer.md — persona that evaluates work across design, quality, security,
  and docs

## Constraints

- Persona files MUST follow the schema defined in personas/README.md.
- Persona filenames MUST be lowercase and short.
- Personas MUST run as subagents only, except maestro.
- Personas MUST NOT reference framework internals or Maestro mechanics.
