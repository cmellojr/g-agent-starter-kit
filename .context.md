The root directory of the G-Agent Starter Kit, a multi-model, pure markdown,
zero-dependency Natural Language AI Harness (NLAH) aligned with Google style
guides and engineering practices.

## Summary

- .agents/ — mirror of the framework files kept in sync by
  `scripts/sync-framework.sh`
- .gitignore — standard Git file exclusions
- AGENTS.md — entrypoint style book auto-loaded by AI agents
- CHANGELOG.md — log of project changes and version updates
- ENTRYPOINT.md — full orchestration boot phrase target for the Maestro persona
- LICENSE — project license terms
- README.md — project overview, setup instructions, and architecture guide
- docs/ — roadmap, contribution guide, and FEATURE-MAP.md
- personas/ — definitions of specialized AI roles (who does the work)
- rules/ — RFC-style constraints and style rules
- skills/ — reusable protocols and procedures, one SKILL.md per directory
- sync-keeper/ — helper script that previews and drives upstream syncs

## Constraints

- Boot sequence MUST start by reading and executing AGENTS.md.
- Persona files and skills MUST follow their respective directory schema.
- `AGENTS.md`, `personas/`, `rules/`, and `skills/` MUST stay identical in the
  root tree and the `.agents/` mirror.

## Guidance

- Extend the framework by adding custom personas, rules, and skills in your
  own fork.
