The root directory of the Agent Starter Kit, a multi-model, pure markdown,
zero-dependency Natural Language AI Harness (NLAH) aligned with Google style
guides and engineering practices.

## Summary

- .gitignore — standard Git file exclusions
- AGENTS.md — entrypoint file for AI agents to boot the Maestro persona
- CHANGELOG.md — log of project changes and version updates
- LICENSE — project license terms
- README.md — project overview, setup instructions, and architecture guide
- docs/ — project roadmap, style alignment, and guidelines
- personas/ — definitions of specialized AI roles (who does the work)
- rules/ — constraints and style rules categorized by authority level
- skills/ — reusable protocols and procedures for AI agent operations

## Constraints

- Boot sequence MUST start by reading and executing AGENTS.md.
- Persona files and skills MUST follow their respective directory schema.

## Guidance

- Extend the framework by adding custom personas, rules, and skills in your
  own fork.
