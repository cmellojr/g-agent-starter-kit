Contains scripting assets and test suites used by the framework for boot CLI
configuration, Markdown style validation, and formatting.

## Summary

- check_markdown.py — Python utility validating Google Markdown style guide
  compliance
- check_markdown_test.py — Unit test suite for check_markdown.py
- maestro-boot-configure-cli.sh — shell script to write persona agent config
  bindings for CLI execution (e.g. OpenCode)
- maestro-boot-configure-cli_test.sh — test suite verifying CLI config
  generation and persona mapping logic
- wrap_markdown.py — Python utility for formatting prose lines in Markdown to 80
  cols

## Constraints

- Shell scripts MUST follow the guidelines in rules/code/code-style-shell.md.
