Contains commandments, which are sacred, absolute, and non-bypassable rules
governing the behavior and workflow of the agents.

## Summary

- Rules in this folder represent sacred, absolute constraints that must never
  be bypassed by any agent or persona.

## Constraints

- Subject lines in Git commit messages MUST be 50 characters or less,
  capitalized, and have no trailing period.
- A blank line MUST separate the subject and body of Git commit messages.
- Commit message bodies MUST be wrapped at 72 characters.
