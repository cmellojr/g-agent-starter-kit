- README.md — rule index, naming guidelines, and file schema

- context-maintenance.md — enforces .context.md and FEATURE-MAP.md updates on
  structural and feature changes

  trust boundaries

## Constraints

- Rule files MUST follow the rules schema in rules/README.md.
- Rule filenames MUST be lowercase and hyphenated.
- Rules MUST NOT be procedural; procedures belong in skills/.
- Coding-scoped rules MUST live under code/.
