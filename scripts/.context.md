Contains repository-level shell utilities. The framework update script keeps
the `.agents/` clone aligned with the remote stable branch.

## Summary

- sync-framework.sh — updates, checks, or retargets the `.agents/` framework
  clone
- sync-framework_test.sh — case-based tests for the update, check, and track
  modes

## Constraints

- The script MUST fail loudly when the framework update fails.
- The script MUST NOT copy files between the project tree and the clone.
